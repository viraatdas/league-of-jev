# league-of-jev

Play League of Legends with Jev, TypeSafe's fast System One model, as your duo
partner. Jev reads the live game state from Riot's local game API, answers a
batch of typed judgment questions in about 100 ms, and tells you what to do.
It never touches your inputs.

See [PLAN.md](PLAN.md) for the architecture, milestones, and setup.
